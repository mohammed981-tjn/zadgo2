# تسليم: ثلاث خلفيات مطعم عامة لصفحة الهبوط

**من:** جلسة Claude Code (محجوبة عن `canva.com`، فلا تستطيع التنزيل بنفسها)
**إلى:** المساعد الذي يملك وصولاً للإنترنت
**المطلوب منك:** أمر واحد ثم دفع النتيجة.

```bash
bash design-drop/download.sh
```

ينزّل الصور الثلاث مباشرة إلى `docs/images/`، ويتحقق أن كل ملف JPEG فعلي أكبر من 20KB،
ويطبع `DONE: 3/3`. ثم احذف مجلد `design-drop/` وادفع.

---

## الصور ولماذا اختيرت

كلها ‎1920×1080‎ JPG، مولّدة في Canva بقيد صريح: **لا نص، لا أرقام، لا أسعار، لا شعارات،
لا هوية مطعم بعينه.** عاينتُ اثني عشر مرشحاً بصرياً واحداً واحداً قبل الاختيار، وتحققت
بعيني من خلوّها من نصوص مشوّهة — وهو أكثر ما تُخفق فيه مولّدات الصور.

| الملف | الشريحة المقصودة | لماذا |
|---|---|---|
| `bg-dining.jpg` | `#values` — العميل | صالة طعام ليلية متناظرة، مصابيح ذهبية دافئة عند الأطراف، ووسط داكن نظيف تماماً يقرأ العنوان فوقه |
| `bg-kitchen.jpg` | `#partners` — أصحاب المطاعم | مطبخ احترافي واضح: أرفف صحون وقدور وشفّاطات، وطاهٍ غير مميّز الملامح، وممر داكن في الوسط |
| `bg-table.jpg` | `#why` — منصة واحدة | لقطة علوية على كتان كحلي، أدوات مائدة ذهبية، وسط عريض خالٍ |

اللوحة اللونية مضبوطة على ألوان الصفحة نفسها: كحلي `#0b1631` و`#061024` وذهبي `#FFC107`.

## بعد التنزيل — الربط بالصفحة (اختياري، إن أردت)

الخلفيات الحالية في `docs/index.html` تدرّجات CSS داخل `.bg`. لإضافة الصورة فوق التدرّج
مع إبقائه طبقةَ تعتيم تحفظ قراءة النص:

```css
#values .bg { background:
    linear-gradient(rgba(6,16,36,.62), rgba(6,16,36,.78)),
    url('images/bg-dining.jpg') center/cover no-repeat; }
```

وقس عليه `#partners` مع `bg-kitchen.jpg` و`#why` مع `bg-table.jpg`.

> **انتبه:** الصفحة تحمل `Content-Security-Policy` فيها `img-src 'self'` — فالصور يجب أن
> تكون داخل المستودع لا من نطاق خارجي. وضعها في `docs/images/` يحقق ذلك.
