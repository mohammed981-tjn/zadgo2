> **تصحيح واقعي (2026-08-15، من فحص المساعد الآخر):** وُصف المشروع
> الثاني هنا سابقاً بأنه «فارغ» و«بيت زاد جو حصراً» — **لم يعد كذلك**:
> يتعايش فيه اليوم ثلاثة مخططات (`ai.*` لزاد جو، و`adcraft.*`، وبقايا
> `agri_*` من zadam)، وسقف الخطة المجانية **مشترك بينها كلها** لا لزاد
> جو وحده — فاحسب حدود التخزين والنداءات على هذا الأساس. وبوابة
> `ai-gateway` منشورة وتعمل فعلاً (إصدار ٤، وفي جداولها بيانات حقيقية).

يبقى المبدأ الثابت: لا بيانات تشغيلية لزاد جو فيه أبداً — لا طلبات ولا
أموال ولا عملاء. مصدر الحقيقة التجاري يبقى Firestore وحده، وما هنا سجلّ
نداءات وأحكام بشرية وأزواج تدريب تُفقد ولا يخسر العمل ريالاً.

## المحتويات

| الملف | دوره |
|---|---|
| `migrations/0001_ai_zadgo.sql` | الجداول الأربعة والدوال واللوحات — القيد `app = 'zadgo'` (مشروع مخصص لا تتسرب إليه سجلات تطبيق آخر) |
| `functions/ai-gateway/index.ts` | دالة البوابة نفسها — **الحلقة التي كانت ناقصة في حزمة «الخطوة صفر»** (وصل عميل Dart والجداول بلا خادم يربطهما) |

## خطوات النشر (مرة واحدة، ~10 دقائق)

1. **الجداول**: من لوحة المشروع الفارغ → SQL Editor → الصق محتوى
   `migrations/0001_ai_zadgo.sql` كاملاً → Run.
2. **الدالة**: Edge Functions → Deploy new function → الاسم `ai-gateway`
   → الصق محتوى `functions/ai-gateway/index.ts` → Deploy.
   (أو بسطر واحد عبر CLI: `supabase functions deploy ai-gateway`)
3. **الأسرار**: Edge Functions → Secrets:
   - `GEMINI_API_KEY` (أو `ANTHROPIC_API_KEY`) — **بيد المالك وحده، لا تُرسل لأي مساعد**
   - `AI_GATEWAY_SECRET` — قيمة عشوائية طويلة (اختياري لكنه موصى به)
4. **فحص**: افتح `https://<project-ref>.supabase.co/functions/v1/ai-gateway/health`
   — يجب أن يظهر `"ok": true` مع حالة المفاتيح.
5. عنوان الدالة هذا هو ما يوضع لاحقاً في `AiConfig.endpoint` داخل التطبيق
   (عميل `ai_gateway.dart` يُنسخ إلى `lib/services/` **مع أول دفعة ذكاء
   فعلية** لا قبلها — قرار موثّق: لا كود ميت في التطبيق).

> ملاحظة الخطة المجانية: المشروع ينام بعد أسبوع خمول. قبل الاعتماد
> التشغيلي الفعلي إمّا خطة مدفوعة وإمّا نقل البوابة إلى Cloud Functions
> بعد Blaze (الجداول تبقى هنا — Postgres أنسب لتحليلات التدريب).

## «جداول احتياطي للمستقبل»

الجداول الأربعة **هي** الاحتياط المستقبلي: `requests` تستوعب أي ميزة ذكاء
قادمة (البحث، المنيو من صورة، الأوصاف، المساعد…) عبر عمود `feature` بلا
أي تعديل بنية، و`feedback` تجمع أحكام البشر، و`v_training_pairs` تُخرج
أزواج التدريب جاهزة. لا نُنشئ جداول فارغة تخمينية — كل ميزة جديدة = صفّ
في `feature_flags` فقط.

## حدود الأمان المطبَّقة في `index.ts`

- مفاتيح المزوّدين لا تغادر أسرار المشروع — التطبيق لا يعرفها.
- سقف الإنفاق يُفحص قبل كل نداء (429 عند التجاوز) — 5$/يوم و50$/شهر
  افتراضاً، تُعدَّل من جدول `ai.budget`.
- هوية المستخدم تُجزَّأ SHA-256 قبل التخزين.
- التخزين المؤقت 24 ساعة على بصمة الطلب — السؤال المكرر لا يُدفع ثمنه مرتين.
- `AI_GATEWAY_SECRET` حاجز أولي فقط (يُشحن في التطبيق فليس سراً حقيقياً)
  — الترقية المقررة قبل الإطلاق العام: تحقق البوابة من رمز جلسة Firebase.
