# مرشحات تصاميم Canva للمعاينة

بيئة هذه الجلسة تحجب نطاقات Canva (`export-download.canva.com` و`media.canva.com`)،
لذا لم يمكن تنزيل ملفات JPG هنا مباشرة. بدلاً من ذلك جرى تصدير التصاميم الاثني عشر
من جديد عبر Canva MCP، وروابط التنزيل الموقّعة الجديدة موجودة في `urls.tsv`
بالتنسيق: `اسم الملف <TAB> معرّف التصميم <TAB> الرابط`.

## التنزيل (من بيئة لها وصول للشبكة)

```bash
bash design-candidates/download.sh
```

ينزّل الملفات a1.jpg .. c4.jpg في هذا المجلد ويتحقق أن كل ملف JPEG فعلي أكبر من 20KB،
ثم يطبع سطراً أخيراً `DONE: <العدد>/12`.

## ملاحظة الصلاحية

الروابط موقّعة ومؤقتة (تنتهي حوالي 02:15–03:10 GMT بتاريخ 2026-08-09).
إن انتهت الصلاحية، أعد التصدير عبر Canva MCP بأداة `export-design`
(بصيغة jpg) مستخدماً معرّفات التصاميم في العمود الثاني من `urls.tsv`.
