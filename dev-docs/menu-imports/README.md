# ملفات استيراد المنيو — المرجع الدائم

ملفات JSON جاهزة للّصق في أداة «استيراد منيو» بتطبيق الأدمن.

## الملفات

| الملف | المطعم | التصنيفات | الأصناف |
|------|--------|-----------|---------|
| `fateer-station.json` | فطير ستيشن | 6 (الفطير، الحلا، البيض، العريكة والمعصوب، المشروبات، الإضافات) | 74 |
| `kabsa-suwailem.json` | كبسة سويلم | 6 (الدجاج، اللحم، الطواجن، السلطات، المشروبات، الحلويات) | 26 |

## طريقة الاستيراد (من تطبيق الأدمن)

1. تبويب **المطاعم** ← بطاقة المطعم ← أيقونة **استيراد منيو**.
2. انسخ محتوى الملف كاملاً والصقه في الحقل.
3. اضغط **تحليل ومعاينة** — تظهر التصنيفات وعدد الأصناف قبل أي كتابة.
4. اضغط **استيراد** — يُكتب كل شيء في دفعة واحدة (كله أو لا شيء).

ملاحظات:

- الوضع الافتراضي **يضيف** ولا يحذف: كرِّره على نفس المطعم تتكرر
  الأصناف. لإعادة استيراد منيو موجود فعّل مفتاح **«استبدال المنيو
  الحالي»** — يحذف القائم كاملاً ثم يستورد الجديد مكانه.
- الصيغة: كائن فيه `categories`، كل تصنيف فيه `name` و`items`، وكل صنف
  فيه `name` و`price` (واختيارياً `kcal` و`description` و`imageUrl`
  و`emoji`).
- أي منيو جديد مستقبلاً: أضف ملفه هنا بنفس الصيغة ليبقى مرجعاً دائماً.
