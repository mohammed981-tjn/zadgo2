# ملفات الدراسة المالية — نسخ الطباعة والمشاركة

| الملف | ماذا يحوي |
|---|---|
| `دراسة-الانطلاق-المالية.pdf` | الدراسة كاملة منسّقة (4 صفحات) — للطباعة والمشاركة مع محاسب أو ممول |
| `عمولات-تطبيقات-التوصيل.pdf` | جدول عمولات المنصات السعودية بأرقام مُدقَّقة من القوائم المالية |
| `study.html` | مولّد ملف الدراسة |
| `commissions.html` | مولّد ملف العمولات |

**النص المصدر** (وهو المرجع عند أي تعارض): `../launch-financial-study.md`.

## إعادة توليد الـPDF بعد أي تعديل

عدِّل ملف HTML ثم:

```bash
chromium --headless --no-sandbox --disable-gpu \
  --print-to-pdf="دراسة-الانطلاق-المالية.pdf" --no-pdf-header-footer \
  "file://$PWD/study.html"
```

(في جلسات المساعد: متصفّح Chromium متاح على `/opt/pw-browsers/chromium`.)

**لماذا HTML لا Word؟** لأن جداول الدراسة عربية RTL متعددة الأعمدة،
وتحويلها من Word إلى PDF كسّر محاذاتها في هذه البيئة — بينما مسار
HTML ← Chromium يخرج مطابقاً للمعاينة في كل مرة.

> يُحدَّث هذا المجلد كلما تغيّرت أرقام الدراسة (العمولة، الرواتب،
> رسوم التأسيس، معايير التوظيف) — النص أولاً ثم يُعاد توليد الـPDF.
